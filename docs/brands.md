# 品牌資料管理與轉換指南 (Brands Data Management)

本專案的品牌與產品資料透過 `docs/brands.xlsx` 進行管理，並由 `tools/convert.go` 轉換為 `data/brands.json` 及全站靜態 HTML（`index.html` 與 `brands/{slug}/index.html`）。

## 1. Excel 欄位定義 (Field Definitions)

`tools/convert.go` 會自動讀取第一個工作表的標題列（不分英文大小寫，忽略前後空白）。以下為目前支援的欄位與實際使用狀況：

### 頁面與轉換實際使用的欄位

| 欄位名稱（支援別名） | 說明 | 範例 |
| :--- | :--- | :--- |
| **Slug** | 品牌唯一識別碼（英文），作為網址路徑 `brands/{slug}/index.html` 與素材目錄名稱。可含連字號 `-`（建議使用小寫英文字母、數字與連字號，不可含空白或斜線 `/`）。若留空或以 `demo` 開頭則會略過該列 | `xinlong`, `ailiao` |
| **品牌名稱** | 品牌完整正式名稱；顯示於品牌頁副標，並用於自動推導「品牌短名」 | `屏東縣枋寮鄉新龍社區發展協會` |
| **Logo** | 品牌標誌檔名（存放於 `public/assets/{slug}/` 下）。顯示於首頁品牌列表與品牌頁導覽列（若留空則首頁與品牌頁皆不顯示標誌） | `L3.jpg` |
| **Hero Image**<br>（別名：`主圖圖片url`、`主圖 url`） | 品牌頁主視覺大圖檔名（存放於 `public/assets/{slug}/` 下）。若此欄與別名皆留空，程式會自動以「第一筆已收錄產品的圖片」（產品名稱留空的項目不計入）作為替代主圖；沒有已收錄產品時不提供備援 | `H3.jpg` |
| **標語** | 品牌一句話簡介；顯示於首頁品牌列表、品牌頁產地旁，以及品牌頁 `<meta name="description">` | `食漁、樂漁、慢漁` |
| **Hero 巨字標語**<br>（別名：`Hero標語`、`Hero巨字標語（以 \| 分隔）`） | 顯示在品牌頁主視覺圖片上的英文裝飾大字，請以 `\|` 分隔 | `SEA \| FOOD \| SLOW` |
| **產地** | 品牌所在鄉鎮（對應 JSON 的 `origin`）。**決定首頁互動地圖的鄉鎮歸屬與頁面顯示的鄉鎮名**（格式要求詳見第 2 節） | `屏東枋寮鄉`、`屏東市` |
| **品牌故事** | 品牌簡介內文。可用換行（`\n`）分段，轉換時每個非空行會獨立產生一個 `<p>` 段落 | `坐擁豐富海洋的環境...` |
| **CTA 文字**（別名：`CTA文字`） | 品牌頁底部的行動呼籲按鈕文字。若填寫了「CTA 連結」但未填文字，按鈕預設顯示「聯絡品牌」 | `前往訂購` |
| **CTA 連結**（別名：`CTA連結`） | 品牌頁底部的行動呼籲按鈕網址。**只有填寫此欄時，品牌頁才會輸出 CTA 按鈕** | `https://...` |
| **產品 [1-10] 名稱**<br>（別名：`產品[1-10]名稱`） | 產品名稱（最多支援 10 項）。若名稱留空則略過該項產品 | `龍膽石斑魚粥` |
| **產品 [1-10] 摘要**<br>（別名：`產品[1-10]摘要`） | 產品特色短評（顯示於品牌頁產品區塊） | `4年以上飼育的龍膽石斑...` |
| **產品 [1-10] 價格**<br>（別名：`產品[1-10]價格`） | 產品售價（頁面自動加上 `NT$` 前綴）。可填 `300`、`1,200`、`NT$300`、`300元` 等格式；若無法解析為有效數字，轉換工具會在終端機印出警告 | `300` |
| **產品 [1-10] 規格**<br>（別名：`產品[1-10]規格`） | 產品包裝規格，與價格並列顯示為 `NT${價格} · {規格}` | `580g/包` |
| **產品 [1-10] 圖片url**<br>（別名：`產品[1-10]圖片url`、`產品 [1-10] 圖片`、`產品[1-10]圖片`） | 產品圖片檔名（存放於 `public/assets/{slug}/` 下） | `B_3_1.png` |
| **產品 [1-10] 連結**<br>（別名：`產品[1-10]連結`） | 產品購買或介紹網址。**有填寫時才會在該產品下方顯示「購買」按鈕** | `https://...` |
| **影片 [1-3] 標題**<br>（別名：`影片[1-3]標題`） | 影片標題（最多支援 3 部，**必填**）。標題與可解析的 YouTube 網址皆須填寫；標題留空會整筆略過。轉換時會自動過濾標題中的 Emoji 圖示 | `漁村體驗紀錄` |
| **影片 [1-3] 網址**<br>（別名：`影片[1-3]網址`） | YouTube 影片連結（需搭配「影片標題」一併填寫才會收錄）。支援 `youtu.be/{id}`、`youtube.com/watch?v={id}`、`youtube.com/embed/{id}` 與 `youtube.com/shorts/{id}`（Shorts 會自動套用直式比例）。網站採點擊後載入 `youtube-nocookie.com` 播放器；若標題留空或網址無法解析出 11 碼 YouTube ID 則會略過該影片 | `https://youtu.be/...` |

> **注意**：
> 1. **新增欄位方式**：目前 `docs/brands.xlsx` 預設僅建立「產品 1～2」、「影片 1」與「徽章 1～2」的欄位；若需填寫第 3～10 項產品、第 2～3 部影片或其他選填欄位，請自行在 Excel 第一列依上表命名規則新增標題欄（例如 `產品3名稱`、`產品3價格`、`影片2標題` 等）。
> 2. **同義欄位優先順序**：`tools/convert.go` 在同義欄位間會依固定優先順序讀取第一個非空值。例如主圖欄位會依序檢查 `Hero Image` → `主圖圖片url` → `主圖 url`；若工作表同時保留多個欄名，請確保修改的是優先讀取的欄位（或保持兩欄一致）。

### 僅寫入 `data/brands.json` 備份（目前頁面未渲染）的欄位

以下欄位仍會由 `tools/convert.go` 讀取並寫入 `data/brands.json`（或保留結構），但目前的 HTML 模板未將其輸出至網頁：
*   **徽章 [1-3]**（`徽章 1`～`徽章 3` / `徽章1`～`徽章3`）：寫入 JSON `badges`。
*   **社群連結**（`LINE 連結` / `LINE連結`、`FB 連結` / `FB連結` / `Facebook連結`）：寫入 JSON `social`。
*   **QRSlug**（`QRSlug` / `QR Slug`）：寫入 JSON `qrSlug`。
*   **SEO 欄位**（`SEO 標題` / `SEO標題`、`SEO 描述` / `SEO描述`）：寫入 JSON `seo`。目前品牌頁 `<title>` 固定使用「`{品牌短名}｜屏東好朋友`」，`<meta name="description">` 則直接使用「**標語**」欄位。
*   **FAQ（常見問題）**：品牌頁模板（`brand.html`）支援在有資料時顯示常見問題區塊，但目前 `tools/convert.go` 並未從 Excel 讀取 FAQ 欄位（`faq` 為 `null`）。

## 2. 「產地（Origin）」欄位與互動地圖鄉鎮對應規則

Excel 的「**產地**」欄位（JSON 中的 `origin`）同時決定了**首頁互動地圖的亮起區域**與**網頁上顯示的鄉鎮名稱**：

1.  **地圖鄉鎮比對規則（格式要求）**：
    *   `tools/convert.go` 會讀取 `public/assets/common/pingtung-map.svg` 中每個鄉鎮 `<path>` 的 `<title>` 第一個詞（即完整鄉鎮市名，包含「**市／鎮／鄉**」後綴，例如：`屏東市`、`內埔鄉`、`萬丹鄉`、`萬巒鄉`、`佳冬鄉`、`枋寮鄉`、`枋山鄉` 等）。
    *   程式以字串包含（`strings.Contains(brand.Origin, town)`）判斷該品牌屬於哪個鄉鎮。
    *   **填寫要求**：「產地」欄位**必須包含完整的「XX鄉」、「XX鎮」或「XX市」名稱**（例如填寫 `屏東內埔鄉`、`屏東縣內埔鄉` 或 `屏東市` 皆可）。**不可省略「鄉／鎮／市」後綴**（例如只寫 `屏東內埔` 會導致地圖無法匹配到 `內埔鄉`）。
2.  **顯示用鄉鎮名稱推導（`townName`）**：
    *   若產地為 `屏東市`，頁面直接顯示 `屏東市`。
    *   其他情況會自動去除開頭的 `屏東縣` 或 `屏東` 前綴（例如 `屏東內埔鄉` 或 `屏東縣內埔鄉` 皆會顯示為 `內埔鄉`）。

## 3. 「品牌名稱」自動產生短名規則 (`shortName`)

首頁品牌列表、地圖標記、品牌頁大標題與「下一站」導覽皆使用由「**品牌名稱**」自動推導出的**品牌短名**（完整名稱仍會顯示於品牌頁大標題下方）：

1.  **社區發展協會**（名稱含 `社區發展協會`）：
    *   先去除結尾的 `發展協會`（保留 `社區`）。
    *   再找名稱中最後一個 `鄉`、`市` 或 `鎮` 字元，將其與前面的縣市鄉鎮前綴一併去除。
    *   *範例*：`屏東縣內埔鄉隘寮社區發展協會` → `隘寮社區`；`屏東縣枋寮鄉新龍社區發展協會` → `新龍社區`。
2.  **屏東縣農會**：
    *   因「屏東縣」為農會名稱本體而非行政區前綴，特例保留完整名稱 `屏東縣農會`。
3.  **其他名稱（如各鄉鎮農會）**：
    *   僅去除開頭的 `屏東縣` 前綴（若有）。
    *   *範例*：`萬丹鄉農會` → `萬丹鄉農會`；`屏東縣佳冬鄉農會` → `佳冬鄉農會`。

## 4. 資產路徑慣例 (Asset Mapping)

轉換程式 `tools/convert.go` 具備自動路徑補全與字元正規化功能：
1.  在 Excel 填入檔名（如 `H3.jpg`）且 Slug 為 `xinlong` 時，程式會自動對應到 `public/assets/xinlong/H3.jpg`。
2.  若填入完整網址（`http`、`//` 開頭）或已包含 `public/assets` 路徑，則會保持原樣（舊有的 `../` 相對路徑前綴會被自動清除）。
3.  **全形轉半形**：檔名中的全形數字與符號（`０`–`９`、`＿`、`－`、`．`、全形空白）會自動轉換為半形，避免因輸入法誤植造成 404 錯誤。

## 5. 新增品牌時的操作步驟

若要在網站新增一個品牌，除了在 `docs/brands.xlsx` 新增一列資料外，還需配合修改 `tools/convert.go` 的固定清單：

1.  **放置品牌素材**：
    *   建立 `public/assets/{slug}/` 目錄，將 Logo、主視覺圖（Hero Image）與產品圖片放入其中，並確認檔名與 Excel 填寫一致。
2.  **更新由北到南的排序清單（`tools/convert.go`）**：
    *   `data/brands.json` 會保留 Excel 工作表的原始順序；但**首頁品牌列表與品牌頁底部的「下一站」循環導覽**是依照 `tools/convert.go` 中 `routeRank()` 寫死的由北到南路線排序：
        ```go
        []string{"pingtung", "ailiao", "wandan", "chengde", "chishan", "jiadong", "xinlong", "fenggang"}
        ```
    *   新增品牌時，請將新品牌的 `slug` 依地理位置插入 `routeRank` 清單的對應位置（未列入清單的品牌排序權重為 `999`，會被排在最後）。
3.  **確認地圖標籤座標（若位於新鄉鎮，選用）**：
    *   若新品牌所在的鄉鎮原本已有其他品牌，地圖會自動將新品牌併入該鄉鎮區塊與標籤。
    *   若新品牌位於**目前尚未有品牌的鄉鎮**，地圖區塊（`<path>`）會自動亮起並可點擊，且該鄉鎮的文字標籤（`<text class="town-label">`）也會**自動根據該鄉鎮幾何路徑置中產生**。只有在預設位置與鄰近標籤重疊、需要微調視覺位置時，才需在 `tools/convert.go` 的 `townshipMap()` 中於 `labelPositions` 指定該鄉鎮的 `(x, y)` 覆寫座標（座標系對應 `public/assets/common/pingtung-map.svg` 的 `viewBox="0 0 1440 2777"`）。
4.  **更新首頁靜態文案與風土分頁（選用）**：
    *   若希望新品牌同步列入首頁「三種風土（`#places`）」的按鈕列表，並更新首頁寫死的品牌與產品總數敘述（如「八個社區協會與農會」），請一併編輯 `index_template.html`（詳見第 6 節）。
5.  **重新執行轉換工具**：
    ```bash
    # 於專案根目錄執行
    go run tools/convert.go
    ```
    執行後會同步更新 `data/brands.json`、`index.html` 以及 `brands/{slug}/index.html`。

## 6. 不在 Excel 中、需直接修改模板或程式的首頁內容

並非所有首頁內容都由 `docs/brands.xlsx` 控制。若要調整以下區塊，請直接編輯 `index_template.html` 或 `tools/convert.go`，修改後再執行 `go run tools/convert.go` 重新生成 `index.html`（**請勿直接編輯生成後的 `index.html` 或 `brands/*/index.html`，因為下次執行轉換時會被覆蓋**）：

*   **首頁 Hero 標題、引言、Meta 描述與產品拼貼（Mosaic）**：
    *   Hero 區的標題與敘述（「八個社區協會與農會，十五件...」）寫在 `index_template.html` 的 `.home-hero` 區塊；頁面 `<head>` 的 `<meta name="description">` 與 `#about` 區塊第一段亦寫死了相同的品牌／產品數量敘述，增減品牌或產品時請一併更新。
    *   右側 7 張產品圖片拼貼（`.specimen-mosaic`）的選品清單，寫死在 `tools/convert.go` 的 `tiles` 篩選陣列中（指定 `slug` 與圖片檔名關鍵字如 `B_8_1`）。
*   **首頁地圖預設圖說**：
    *   地圖下方的初始文字 `<p class="map-caption">屏東縣農會 · 屏東市</p>` 寫在 `index_template.html`（載入後會由 `app.js` 依目前捲動或點擊的品牌動態更新）。
*   **「三種風土」區塊（`#places`）**：
    *   包含「大武山腳」、「屏東平原」、「南方海岸」三個分頁的標題（含「山腳下的三個社區」、「海風吹過的三個地方」等數量敘述）、介紹文案、配圖路徑與品牌連結（`.place-actions`），全部寫死在 `index_template.html` 的 `<section id="places">` 中。新增品牌時不會自動列入，需手動於對應風土分頁加入品牌連結。
*   **「關於計畫」區塊（`#about`）**：
    *   計畫介紹信件內文（第一段含「屏東八個社區發展協會與農會」敘述）、頭像配圖與署名（「屏東縣政府 農特產品牌計畫」）全部寫死在 `index_template.html` 的 `<section id="about">` 中。
*   **頁尾（Footer）**：
    *   頁尾背景圖、版權年份與屏東縣鄉鎮地圖 CC BY-SA 4.0 授權標示，定義於 `index_template.html` 底部的 `{{define "footer"}}` 模板區塊（首頁與所有品牌頁共用）。
